# tvbox-iptv

Плейлист российских каналов для Android-приставки, который собирается и проверяется прямо на ней.

Источники — публичные плейлисты из агрегатора [m3u.su](https://m3u.su) и iptv-org. Приставка сводит одинаковые
каналы из разных источников, проверяет каждый поток и в плейлист берёт лучший живой вариант.

## Как работает на приставке

- `box/agg.py` работает в Termux, автозапуск через Termux:Boot (`box/run.sh` перезапускает его при падении).
- Плейлист для плеера: `http://127.0.0.1:8090/playlist.m3u` (основные каналы, затем остальные по группам).
  Статус проверок: `http://127.0.0.1:8090/status`.
- Как часто проверяет: основные каналы — раз в 30 мин, все каналы — раз в 2 ч, полная перепроверка всех вариантов — раз в 12 ч.
- Обновления: раз в 12 ч приставка читает `box/manifest.json`. Если версия выросла, она скачивает файлы, сверяет sha256,
  делает самопроверку и перезапускается. Если новая версия трижды подряд падает при старте, приставка откатывается
  на прошлую и больше её не берёт.

## Как менять (можно прямо на сайте GitHub)

- **Список основных каналов и их синонимы:** `box/channels.py`
- **Источники и интервалы:** `box/config.json`. Источник задаётся коротким кодом m3u.su (`de0`, `so`, …) или полной ссылкой.

После коммита в `box/` GitHub Action (`.github/workflows/manifest.yml`) делает самопроверку и поднимает версию
в `box/manifest.json`. Вручную manifest не трогайте.

## Установка на новую приставку

1. Установить Termux и Termux:Boot (APK с GitHub: termux/termux-app, termux/termux-boot), открыть Termux:Boot один раз.
2. В Termux:
   ```
   curl -sL https://raw.githubusercontent.com/viafoggy-dotcom/tvbox-iptv/main/tools/setup.sh | sh
   ```
3. В IPTV-плеере (например, TiviMate) добавить плейлист `http://127.0.0.1:8090/playlist.m3u`.
